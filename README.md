# 1029 課堂作業：AI 導演思維 × Scrollytelling 互動微動效

* **主題**：法式海綿蛋糕手作工藝（Option B 延伸主題）
* **作者**：吳芯沫 
* **主要檔案**：`w1.html`

## 🌟 作業實作重點
1. **AI 導演提示詞公式**：運用 `[鏡頭運鏡與焦段] + [主體描寫與具體動作] + [環境與光影細節]`，為 Hero 區塊打造具備 35mm 鏡頭語言的高質感視覺描述。
2. **Scrollytelling 滾動敘事**：結合 Tailwind CSS、GSAP 與 ScrollTrigger，達成平滑 SVG 滾動畫線、階段文字 Pin 互動及 HUD 快速跳轉。
3. **加分挑戰 1（動態背景）**：於網頁底層配置全螢幕 `<video>`，並正確設定 `autoplay loop muted playsinline` 屬性與低透明度穿透。
4. **加分挑戰 2（物理阻尼感調校）**：將 GSAP `scrub` 數值設定為 `1.5`，營造溫潤流暢的烘焙視覺沉浸感。
